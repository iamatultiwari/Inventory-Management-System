
# Inventory-Management-System

lightweight Inventory Management System for a small retail store.
Store staff need to log in, add new products to stock, and view the current inventory at a glance.

## Tech Stack
mern

###  Frontend
- React.js
- JavaScript
- HTML
- CSS

###  Backend
- Node.js
- Express.js
- RESTful APIs

###  Database
- MongoDB
- Mongoose


## 🔄 Application Workflow

1. User signs up or logs in
2.Add New Product
3. filter (low stock < 10 && all)
4. view total stock
5. logout


---

🔹 Backend Setup
cd backene
npm install
npm run dev

🔹 Frontend Setup
cd frontend
npm install
